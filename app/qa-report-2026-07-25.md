## Issues Found

### ISSUE-001 — CRITICAL: Invalid hook call breaks app rendering
- **Severity:** Critical
- **Category:** Functional
- **Root cause:** `Layout.tsx` re-exported `navGroups` and `getEnabledNavGroups` from `Sidebar.tsx`, breaking Vite Fast Refresh HMR. This caused "Invalid hook call" in ThemeProvider and prevented React from mounting.
- **Fix:** Removed the re-export. No other file imports these from Layout.
- **Commit:** `61716e9`
- **Status:** ✅ Verified — app loads correctly after fix + Vite cache clear

### ISSUE-002 — MEDIUM: GoTrueClient multiple instances warning
- **Severity:** Medium  
- **Category:** Console
- **Description:** `Multiple GoTrueClient instances detected in the same browser context` warning appears on page load. Not an error but may cause undefined behavior with concurrent auth operations.
- **Status:** Deferred — requires investigation of Supabase client initialization

### ISSUE-003 — LOW: Onboarding modal reappears on every navigation
- **Severity:** Low
- **Category:** UX
- **Description:** The onboarding modal ("Passer"/"Suivant") reappears after navigating between pages. Should only show once or be dismissible persistently.
- **Status:** Deferred
